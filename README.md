## What's Inside

This is a fully linked, 3-statement DCF model built from scratch in Microsoft Excel.
Every forecast cell is a formula. Every assumption is documented. Nothing is hardcoded.

**Excel Model — 7 sheets:**

| Sheet | Purpose |
|---|---|
| `Assumptions` | Single control panel — all inputs live here |
| `Revenue` | Segment-level forecast (Home Care, BPC, F&R) |
| `P&L` | Revenue → EBITDA → EBIT → PAT |
| `BS` | Working capital, capex schedule, net debt |
| `FCF` | NOPAT → Free Cash Flow to Firm (FCFF) |
| `DCF` | PV of FCFFs + Terminal Value → Intrinsic Value |
| `Sensitivity` | 7×7 WACC vs growth rate matrix |

**PDF Report — 7 pages:**
- Company overview and recent corporate updates
- Key financial metrics (FY20A–FY25A)
- Income statement and segment revenue projections
- Balance sheet highlights
- Free cash flow build
- WACC calculation and DCF valuation output
- Sensitivity analysis with colour-coded matrix
- Ratio analysis, DuPont decomposition, peer comparables

## Valuation Conclusion

Our base-case DCF yields an intrinsic value of **₹1,508/share** — implying 36.4% downside from CMP.

This is consistent with HUL's historical pattern of trading at a structural premium to intrinsic value.
The market is pricing in brand franchise, structural negative working capital (CCC of −61 days),
95%+ dividend payout consistency, and near-monopoly rural distribution — qualities a DCF
does not fully capture.

At 8.0% WACC and 6.5% terminal growth (bull case), our model implies **₹2,645** — much closer
to CMP, suggesting the market is pricing an optimistic but not irrational scenario.
